## 原生家宽 IP 和机房 IP，差的不是速度

“原生 IP”在跨境圈里的通行定义是：这个 IP 的注册地和归属 ISP 都在印尼本地，平台侧看到的是一次本地宽带用户的访问。机房里批量开出来的 IP 归属写的是云服务商的数据中心段，段本身没错，只是性质不一样。

机场节点的问题更直接。一个节点几十上百人共用，出口 IP 相同，行为模式还高度相似，做长期账号环境本身就容易出问题；再加上多数机场节点是机房 IP，且不支持 24 小时常挂。

所以判断规则其实很简单：

- **需要平台认定你是印尼本地用户**（账号环境、直播推流、本地化运营）→ 机房 IP 不够用，得看原生家宽。
- **只需要一个雅加达出口**（建站、接口、CDN 回源、延迟测试）→ 机房 IP 完全够，$3–12 能买到配置更高的机器，为“原生”两个字多付的钱收不回来。

有一条要提前说清：IP 只是必要条件之一。有测评作者称自己三个号挂在同一个 IP 上没出现零播放或限流，前提是内容本身没问题。这句只能当个人经验看，不是效果承诺，平台的风控规则也不公开。

## 下单前后要核对的五件事

1. **内存实际值。** 512MB 还是 1GB，结算页写什么就是什么。
2. **退款条款。** 现有资料提到 3 天内且流量不超过 10GB 可申请退款至账户余额，原路退回另扣手续费；3–10 天按天扣减比例；超过 10 天不支持。措辞来自第三方转述，具体条件和手续费以官网条款页原文为准，别按“三天无条件退”理解。
3. **优惠码是否生效。** `WePCMON90` 和 `WePCYEAR80` 在结算页实际填一遍，看到价格变化再付款。
4. **IP 归属地。** 开机后先用 IP 归属查询工具看注册地和 ASN，确认落在印尼本地 ISP 而不是机房段，再决定要不要长期续。这一步是整篇文章里最值得花五分钟的动作。
5. **库存。** 有测评提到会缺货，赶上活动可能要等补货，急用的话先确认有货再规划时间。

**印尼 VPS 一定要原生 IP 吗？**
看你拿它做什么。账号环境、直播推流这类需要平台识别为本地用户的场景，机房 IP 不够用；建站、接口、测试不需要，机房 IP 更便宜。

**移动、联通、电信分别怎么连？**
移动先直连试，官方口径是“部分移动优秀”；联通和电信建议配中转，中转线路另计 AUD$29.90/月，且该线路不支持联通用户，联通用户需要另找方案。

**能不能只买一个月？**
可以，月付就是为这个准备的。先跑一个月验证 IP 和延迟，再决定转不转年付，比直接年付稳妥。

**和 Evoxt 雅加达 $2.99 的差在哪？**
差在 IP 性质，不在配置。Evoxt 那台是数据中心 IP、配置还更高，适合建站和跑服务；WePC 卖的是印尼原生家宽 IP，面向需要本地归属的账号场景。两者解决的不是同一个问题。
